A comprehensive profile management plugin for WordPress users and advanced user profiles.

== Description ==

Ecosys Profile Manager allows you to create and manage advanced user profiles with custom fields and extended functionality.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/ecosys-profile-manager` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use the plugin settings to configure your profile options.

== Frequently Asked Questions ==

= How do I create custom profile fields? =

Custom profile fields can be created through the plugin's admin interface.
